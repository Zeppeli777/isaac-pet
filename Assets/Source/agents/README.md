# Magdalene source assets

These two PNG files were supplied by the user for the Magdalene Agent visual work:

- `magdalene-character-002.png` — original character/costume sheet, 512×512 RGBA.
- `magdalene-golden-locks.png` — original Golden Locks strip, 512×64 RGBA.

They are source material only and are deliberately not copied into the application bundle. The current runtime asset is the reviewed 192×192 portrait at `Resources/Agents/magdalene-portrait.png`, cropped from the character sheet.

Do not treat either source sheet, or the portrait, as a complete desktop-pet skin. A selectable Magdalene skin must be independently assembled and validated as a 1536×2288 (8×11) WebP atlas at `Resources/Agents/magdalene-spritesheet.webp`.
